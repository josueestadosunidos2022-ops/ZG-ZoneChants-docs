# ZoneChants — 2026-10-17

## English — SERVER ONLY

Adds item diagnostics, main-hand limit correction, bounded repair utilities, the server-only Ascua effect and an editable collection catalog. Reload validates the four TOML files together; existing settings are preserved. Ascua applies to supported positive vanilla melee player damage and is not a client enchantment registry entry.

Minecraft 1.20.1 / Forge 47.x / Java 17. ZoneCore: required (server). Stop the server/client before replacing JARs, keep only one version per side, and back up the world/configuration.

 Public protected distribution; private sources, obfuscation mappings and production account/configuration files are not included. Java obfuscation is not an absolute anti-decompilation guarantee. Original release checks and isolated protected-server startup are documented separately; graphical client, real multiplayer and full-modpack behavior are not certified by this upload.

## Español — SOLO SERVIDOR

Añade diagnóstico de objetos, corrección del límite en mano, utilidades de reparación acotadas, el efecto Ascua solo de servidor y un catálogo de colección editable. La recarga valida conjuntamente los cuatro TOML y conserva ajustes existentes. Ascua se aplica al daño cuerpo a cuerpo vanilla positivo compatible; no es un encantamiento registrado en el cliente.

Detén ambos lados antes de sustituir los JAR, deja una versión por lado y respalda mundo/configuración. Distribución pública protegida sin fuentes, mapas de ofuscación ni datos privados de producción. Las pruebas locales no certifican cliente gráfico, multijugador real ni modpack completo.
